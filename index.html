DuDu Publisher

A desktop publishing tool for uploading original Learn Chinese with DuDu videos to TikTok.

What it is

DuDu Publisher is a self-use desktop tool operated by the creator of Learn Chinese with DuDu. It packages a video produced by the creator and posts that single video to TikTok on the creator’s own behalf.

The TikTok app registered for this tool is named DuDu Publisher and is filed under the Education category.

What it connects to

  • TikTok Login Kit — lets the account owner authorize DuDu Publisher to sign in to their own TikTok account and to read basic profile information.
  • TikTok Content Posting API — uploads an original Learn Chinese with DuDu video and publishes that video as a post on the authorized account.

What it does

  1. Authorizes a TikTok account through the TikTok Login Kit.
  2. Reads the authorized account’s basic profile information.
  3. Uploads an original Learn Chinese with DuDu video.
  4. Publishes original content using the Content Posting API.
  5. Does not sell user data.

DuDu Publisher is not used for third-party user marketing, bulk or spam posting, or any unauthorized operation of an account.

Scope and limits

This tool operates only on the account that grants it authorization, and only when its operator starts a publish action. Access tokens are used solely to perform the API operation the operator requested.

DuDu Publisher is an independent project. It is not affiliated with, endorsed by, or sponsored by TikTok or ByteDance.
